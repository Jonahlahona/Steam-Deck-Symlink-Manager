The Compatdata folder is a nightmare of tedium and this tool aims to stop (or mitigate) that tedious process and allow you to clean up after Steam. Having to do the whole rigamarole of trying the space saving process manually was time consuming if I just wanted to hop on and play. This app lets you conveniently scan, inspect, and safely move those folders over to your SD card, then automatically links (symlinks) them back so Steam thinks they never left!

---

## ⚡ What it actually does:
* **Autodetects everything**: Finds your internal Steam install and mounted SD card automatically so you don't find each path and split screen your file explorer windows
* **Resolves those annoying AppIDs**: Maps the raw numbered folder names (like `814380`) to actual readable game titles (like `Sekiro: Shadows Die Twice`) after some loading. The cache file is stored alongside the launcher.
* **One-Click (Really Two-Click) Relocation**: Safely moves folders between the SSD and SD Card and manages the symlinks for you under the hood.
* **Easy Cleanup**: Any compatdata left over from uninstalled games can be removed as well.
